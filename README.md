# Практическая работа № 2 — WCET

## Требования
- Python 3.10+
- Дополнительные библиотеки не нужны.

## Запуск
Из корневой папки проекта:
```bash
python src/main.py
```
Или укажите другой JSON:
```bash
python src/main.py data/example.json
```

## Входные данные
`data/example.json` содержит модель процессора, дедлайн и список операций.
Для каждой операции задаются `name`, `op_type`, `memory_accesses`, `branches`.

## Модель
- BCET: одна базовая стоимость на операцию.
- WCET: базовая стоимость + число обращений к памяти × штраф промаха + число ветвлений × штраф ошибки предсказания.
- Коэффициент недетерминизма: WCET / BCET.

Это учебная оценочная модель из задания, а не измерение реального процессора.
