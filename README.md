## О программе

WCET — консольная программа на Python для оценки времени выполнения фрагмента кода в простой модели процессора.

Программа рассчитывает:
- **BCET** — время выполнения в лучшем случае;
- **WCET** — время выполнения в худшем случае;
- коэффициент недетерминизма — отношение WCET к BCET;
- вклад промахов кэша и ошибок предсказания ветвлений;
- соблюдение заданного дедлайна.

Параметры процессора, список операций и дедлайн задаются во входном JSON-файле. Для примера используется обработчик прерывания датчика.

Это учебная оценочная модель, а не измерение реального времени работы процессора.

## Требования

- Python 3.10 или новее.
- Сторонние библиотеки не требуются.

## Установка

1. Установите Python 3.10 или новее с официального сайта: https://www.python.org/downloads/
2. Склонируйте репозиторий:

   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   ```

3. Перейдите в папку проекта:

   ```bash
   cd lab1_srb
   ```

Если проект уже скачан архивом, распакуйте его и откройте терминал в корневой папке проекта.

## Запуск

Для запуска программы с примером входных данных выполните из корневой папки проекта:

```bash
py src/main.py
```

Чтобы указать другой файл с входными данными:

```bash
py src/main.py data/example.json
```

Программа выведет таблицу операций, BCET, WCET, коэффициент недетерминизма, вклад источников задержек и результат проверки дедлайна.

## Запуск тестов

Если папка `tests/` содержит автоматические тесты, запустите их командой:

```bash
py -m unittest discover -s tests -v
```
